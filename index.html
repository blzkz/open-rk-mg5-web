Panel RK MG5

      
Versión web 

      
Panel de control de código abierto para el ratón Royal Kludge MG5: DPI, sondeo, sensor, energía,
        botones y perfiles. Funciona en el navegador con WebHID, sin instalar nada. El RK M30 tiene soporte
        experimental, aún sin probar con un ratón real.

      
Royal Kludge, MG5 y M30 son marcas de sus respectivos propietarios. Este proyecto no está
        afiliado ni respaldado por Royal Kludge. El protocolo HID se ha documentado a partir del configurador
        web oficial y de pruebas con el propio ratón, con fines de interoperabilidad.
